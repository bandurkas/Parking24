# Дизайн-система Parking24 — «МТС-синий» (утверждена 18.08.2026)

> Утверждённый борд: `docs/design_boards/board1_mts_blue.png` (выбор заказчика, share-ссылка Higgsfield).
> Плюс решение: слоган **«Паркуйтесь. Летите. Мы присмотрим.»** (из board2) — главный заголовок hero.
> Ориентир стиля — moskva.mts.ru: деловой и дружелюбный. Подтверждено ui-ux-pro-max: паттерн Trust & Authority.

## 1. Токены

| Токен | Значение | Использование |
|---|---|---|
| `--color-primary` | `#0A6CFF` | CTA, ссылки, акценты, активные состояния |
| `--color-primary-dark` | `#0857CC` | hover CTA |
| `--color-navy` | `#0B2D5B` | футер, тёмные поверхности, сайдбар CRM |
| `--color-bg` | `#FFFFFF` | фон страницы |
| `--color-surface` | `#F3F6FB` | подложки секций, поля форм |
| `--color-text` | `#131A24` | основной текст |
| `--color-text-muted` | `#5A6B80` | вторичный текст |
| `--color-border` | `#E1E8F2` | границы карточек, разделители |
| `--color-success` | `#0EA968` | оплачено, возврат выполнен, свободно |
| `--color-warning` | `#F5A300` | ожидает оплаты, напоминание |
| `--color-danger` | `#E23D3D` | отмена, ошибка, занято |
| Радиусы | карточки 16px, кнопки/поля 12px, чипы 999px | как на борде |
| Тени | `0 8px 24px rgba(11,45,91,.08)` | карточки на белом |
| Сетка | 8px; контейнер max-w-6xl | по борду |
| Шрифт | **Golos Text** (400/500/600/700), кириллица | заголовки 600–700, текст 400 |
| Цифры | `font-variant-numeric: tabular-nums` | цены, таблицы, таймеры |

Тёмная тема в v1 не выпускается (светлый дизайн под улицу/солнце), токены позволяют добавить позже.

## 2. Как каждый модуль ТЗ ложится в этот дизайн

| Модуль ТЗ | Дизайн-решение в стиле борда |
|---|---|
| **Главная** (ТЗ §5) | Ровно по борду: hero-фото парковки + белая карточка калькулятора; слоган «Паркуйтесь. Летите. Мы присмотрим.»; 4 карточки преимуществ; чип «Сегодня забронировано N мест»; тарифные карточки с синей полосой снизу; галерея фото; карта с кнопкой «Маршрут в навигаторе»; тёмно-синий футер |
| **Визард брони** (ТЗ §6.1) | Та же белая карточка калькулятора, растянутая в пошаговую форму: сегментный прогресс (1–4) сверху, одна группа полей на шаг, синяя CTA внизу, серые info-блоки для условий отмены. На мобильном — полноэкранные шаги |
| **Оплата ЮKassa** (ТЗ §6.2) | Виджет ЮKassa встраивается внутрь той же карточки (белый фон, радиус 16) — визуально «свой». Чек условий отмены — обязательный чекбокс перед кнопкой оплаты |
| **Отмена/возврат** (ТЗ §6.3) | Страница «Управление бронью»: карточка брони со статус-чипом (цвета из семантики: синий — подтверждена, amber — ждёт оплаты, зелёный — возврат выполнен, красный/серый — отменена). Кнопка отмены — danger-outline + диалог подтверждения с суммой возврата прописью |
| **Комнаты отдыха** | Шаблон «услуга»: hero поменьше + карточки номеров как тарифные карточки + галерея. Тот же визард брони |
| **Передержка животных** (ТЗ §7, фаза 2) | Тот же шаблон «услуга» с иконкой лапы (Lucide `paw-print`): условия приёма списком с галочками, карточки цен, визард с шагом «данные питомца». Ничего нового в дизайне изобретать не нужно — это и есть смысл универсального Resource |
| **CRM `/admin`** (ТЗ §8) | Те же токены, плотность выше (spacing 8/12): сайдбар цвета navy (как футер), контент на `--color-surface`; канбан-колонки = статусы конвейера, карточка брони = белая карточка 12px радиуса со статус-чипом и лентой активности; таблица с tabular-nums; фильтры-чипы |
| **Экран охраны** (ТЗ §8.4) | Упрощённый мобильный список «Сегодня»: крупные строки (гос. номер + место + время), высокий контраст, кнопка «Заехал»/«Выехал» на всю ширину — работа в перчатках на улице |
| **Дашборд владельца** (ТЗ §11) | Карточки метрик как benefit-карточки борда + графики по скилу dataviz (загрузка, источники, выручка); семантические цвета не конфликтуют с primary |
| **Единое окно сообщений** (ТЗ §10) | Двухпанельный лейаут: список диалогов (чипы каналов MAX/WA/TG своими фирменными цветами — только в чипах) + тред. Вложен в CRM-оболочку |
| **Мобильная версия** (ТЗ §4.2) | Нижняя закреплённая панель: [Забронировать — primary] [Позвонить — outline], safe-area inset; калькулятор — первый экран; меню — полноэкранный оверлей |
| **PWA → приложение** (ТЗ §12) | Иконка: белая эмблема на синем #0A6CFF скруглённом квадрате; manifest с theme-color #0A6CFF; те же токены переедут в React Native |
| **Трастовый слой** (ui-ux-pro-max) | Бейджи «Охраняется 24/7», «500 м от Шереметьево», «Договор хранения», реквизиты ООО в футере, счётчик броней — соц. доказательство |

## 3. Копирайтинг

Тон — дружелюбно-деловой (как МТС): короткие человеческие фразы + предельно чёткие цифры.
Заголовки-глаголы («Паркуйтесь», «Забронировать место»), никакого канцелярита.
Все цены с ₽ и «/сутки», tabular-nums. Условия отмены — всегда до оплаты, простым языком:
«Отмените более чем за 24 часа — вернём всю сумму автоматически».

## 4. Правила качества (чек-лист перед каждым релизом страницы)

- Контраст текста ≥ 4.5:1; фокус-состояния видимы; touch-таргеты ≥ 44px
- LCP < 2.5s на 4G: фото WebP ≤ 200KB, hero-фото с priority, остальное lazy
- Нет горизонтального скролла на 360px; проверка 375/768/1024/1440
- `prefers-reduced-motion` уважается; анимации 150–300ms, только transform/opacity
- Один primary CTA на экран; вторичные — outline/ghost
