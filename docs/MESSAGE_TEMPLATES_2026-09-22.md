# Сообщения клиенту (редакция 3, 22.09.2026)

Тексты, которые получает клиент в выбранный им мессенджер. Составлены разработчиком, финальную редакцию утверждает заказчик (Влад).

**Вид сообщений — строгий, без эмодзи и без выделений** (решение пользователя 22.09). Причина: так сообщение одинаково выглядит в Telegram, WhatsApp и MAX, ничего не ломается на спецсимволах и сохраняется деловой тон. Читаемость держится на коротких строках и пустых строках между блоками.

Правила набора, которым подчиняются все тексты:
- первая строка — обращение, вторая — кто пишет (в первом сообщении);
- блоки разделены пустой строкой, внутри блока строки короткие;
- данные брони идут парами «Подпись: значение», в одном порядке во всех сообщениях;
- одно сообщение решает одну задачу и заканчивается тем, что клиенту делать;
- телефон всегда в конце, в одном и том же виде: +7 905 525-06-60.

## Когда что уходит

| № | Сообщение | Момент отправки |
|---|---|---|
| 1 | Место забронировано | Сразу после заявки: автоподтверждение или подтверждение администратором |
| 2 | Напоминание | За 24 часа до планового заезда. Не отправляется, если бронь создана позже этого момента |
| 3 | Автомобиль принят | При переходе в «Заехал» |
| 4 | Спасибо и отзыв | Через 2 часа после «Выехал» |

Первое сообщение самодостаточно: при брони «на завтра» напоминания не будет.

## Сообщения вне основной цепочки

Тексты из ТЗ заказчика, приведены к тем же правилам набора.

**Мест нет (автоотклонение)**
```

К сожалению, на выбранные даты свободных мест нет, поэтому бронь не подтверждена.

Заявка № {{booking.number}}
Даты: {{booking.dates}}

Будем рады видеть вас в другие даты. Подобрать свободные — ответьте на это сообщение или позвоните: +7 905 525-06-60.
```

**Заявка отклонена (администратором)**
```
{{greeting.hello}}
К сожалению, ваша заявка № {{booking.number}} отклонена.

Будем рады видеть вас в другие даты. Ответьте на это сообщение или позвоните: +7 905 525-06-60.
```

**Бронь изменена**
```

Если что-то не так, ответьте на это сообщение или позвоните: +7 905 525-06-60.

```

## Переменные

| Переменная | Что подставляется |
|---|---|
| `{{greeting.hello}}` | «Здравствуйте, Иван!» или «Здравствуйте!», если имени нет |
| `{{greeting.name}}` | «Иван, » или пустая строка — для продолжения фразы со строчной буквы |
| `{{booking.number}}` | номер заявки |
| `{{booking.contract}}` | номер договора, 001 — присваивается при заезде |
| `{{booking.arrival}}`, `{{booking.departure}}` | «17 сентября, 10:00» |
| `{{booking.dates}}` | «17 сент → 19 сент» |
| `{{booking.days}}` | «3 суток», «1 сутки», «21 сутки» |
| `{{booking.vehicle}}` | «Легковая А123ВС77» |
| `{{booking.amount}}`, `{{booking.due}}` | сумма брони и остаток к оплате |
| `{{booking.dueLine}}` | «К оплате на месте: 1 050 ₽, наличными или картой.» или «Бронь оплачена.» |
| `{{booking.transferLine}}` | про трансфер: бесплатный от 4 суток либо платный |
| `{{booking.returnLine}}` | как вызвать трансфер после прилёта |
| `{{booking.checkedInAt}}` | фактическое время заезда |
| `{{links.route}}`, `{{links.review}}` | ссылки из настроек CRM |
| `{{site.url}}` | адрес сайта |

Тексты редактируются в CRM, разметка не используется, поэтому заказчик может править их без риска что-то сломать.

## Что осталось подтвердить у заказчика

1. **Как клиент добирается от терминала до парковки после прилёта.** Вопрос 22.09 был понят как вопрос о возврате денег (ответ: деньги возвращает администратор на ресепшене, наличными). Остаётся сам порядок: клиент звонит, и трансфер приезжает к терминалу? Есть ли точка встречи? От этого зависит `booking.returnLine`.
2. **Цена платного трансфера** при стоянке меньше 4 суток. Сейчас «стоимость подскажет администратор»; если цена фиксированная, лучше назвать её сразу.
3. **Ссылки:** маршрут и отзывы (от Яши).
