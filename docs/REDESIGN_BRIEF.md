## 1. Анти-дубликация (мультиагентно)
- 3 роли: Копирайтер/контент-стратег → UI/UX-дизайнер → Креативный директор (финальные решения).
- Смысловая карта: факт → первое появление → повторы → нужен ли каждый.
- Решения ТОЛЬКО из набора: KEEP / KEEP+REDESIGN / MERGE / MOVE / REWRITE / REDESIGN / REMOVE.
- REMOVE разрешён только если не ломает композицию/сетку/баланс; на месте удалённого не оставлять дыр — переосмыслить блок (структура, акцент, новая полезная инфа, hierarchy, grid).
- Hero-чипы (Охрана 24/7, Видеонаблюдение, Трансфер от 4 суток): проверить, где показывать впервые; из hero автоматически НЕ удалять; повторы ниже заменять новым полезным контентом.
- Повторение CTA — норм; повтор характеристики в hero+карточке+benefits+перед CTA — проверять.
- Итоговый отчёт: Executive Summary; Content Audit (Element/Location/Duplicate/Action/Reason); Design Audit (+Priority Critical/High/Medium/Low); IA (first appear / not repeat / acceptable repeat); Recommended Page Structure; Specific Changes по секциям; Typography/Color/Spacing recs; Mobile audit; MUST/SHOULD/NICE.

## 2. Цветовая система (BLACK+GRAY+WHITE+ORANGE)
- Пользователю текущий оранжевый «пока не нравится» (док написан ДО палитры #F08521 от 20.08 — уточнить актуальность!). Не принимать текущий как финал без сравнения.
- 5–7 кандидатов оранжевого (warm/premium/deep/muted/digital/к красному/к жёлтому) с HEX/RGB/HSL, характером, контрастами к white/black/gray, где использовать, плюсы/минусы → выбрать 1.
- Оранжевый = accent (CTA/highlights), НЕ красить всё (кнопки+бейджи+заголовки+иконки+рамки одновременно = ничего не главное).
- Semantic roles: PRIMARY/ACCENT/BACKGROUND/SURFACE/TEXT PRIMARY/TEXT SECONDARY/BORDER/CTA PRIMARY/CTA SECONDARY/HOVER/ACTIVE/DISABLED/SUCCESS/WARNING/ERROR.
- Грейскейл: не #000+#808080+#fff, а near-black/dark/medium/light gray/off-white/white с ролями.
- Контраст: обычный текст ≥4.5:1, крупный ≥3:1; если orange не работает с белым текстом — НЕ заставлять (тёмный текст/др. оттенок).
- Проверить orange на white/black/gray, как кнопку/текст/иконку/бордер/фон/градиент; на mobile при ярком свете.
- 3 концепции (Premium: Black+White+sophisticated Orange; Modern Tech: White+Gray+energetic Orange+Black; Bold: Black+Orange+White) → выбрать одну.
- FINAL: Recommended Orange #XXXXXX, палитра-таблица, почему, где использовать/где нельзя, CTA primary/secondary, hover/active/disabled.
- Принцип: Black=authority, White=clarity, Gray=structure, Orange=energy/action.

## 3. Баланс белого («слишком много белого, местами пусто»)
- НЕ решать добавлением чёрного/оранжевого повсюду; создать баланс White/Off-White/Light Gray/Gray/Black/Orange.
- Различать WHITE COLOR и WHITESPACE: проверить также высоту секций, паддинги, размер типографики, плотность контента, наличие визуальных элементов — причина «пустоты» может быть не в цвете.
- Убрать «white wall» (несколько белых секций подряд) через ритм поверхностей; пример: WHITE → LIGHT GRAY → WHITE → DARK → WHITE → LIGHT GRAY → BLACK/ORANGE CTA (адаптировать под сайт).
- Surface-система 1-6 (Pure White → Black); серый создаёт иерархию, но сайт не должен стать серым.
- Black стратегически: крупные секции/CTA/footer/pricing/testimonials как visual break — но не превращать сайт в black/orange.
- Карта: | Section | Background | Purpose (Attention/Explanation/Benefits/Trust/Conversion) |.
- 3 концепции: A Light Premium (минимум правок) / B Modern Balanced (глубина) / C Bold Brand → выбрать c обоснованием; финальный ориентир соотношения White:Gray:Dark:Orange.
- Финальный вопрос: «Открыв сайт впервые — он слишком белый?» Если нет — остановиться.
